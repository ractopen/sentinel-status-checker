# Sentinel Security — Unified Deployment & Health Checker

A lightweight GitHub Pages dashboard that checks the live health, cold-start/compiling state, database ping, and HTTP status of all Sentinel Security deployments:

- **Backend API Gateway (Render)**: `https://backend-pi68.onrender.com`
- **Web IAM Portal (Vercel)**: `https://web-beta-orcin-33.vercel.app`
- **Platform Control Plane (Vercel)**: `https://sentinel-control-green.vercel.app`
- **SSO Demo Apps (Vercel)**: Acme HR, FinTech Payroll, and Nexus Ops
